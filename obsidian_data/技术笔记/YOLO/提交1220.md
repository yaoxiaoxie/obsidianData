#### 撰写内容要求（可加页）：

**1. 毕业设计（论文）综述（题目背景、研究意义及国内外相关研究情况）**

**(1) 题目背景与研究意义**
随着人工智能与物联网技术的飞速发展，智能交通系统（Intelligent Transportation Systems, ITS）已成为智慧城市建设的核心组成部分。在ITS中，自动驾驶技术和高级辅助驾驶系统（ADAS）正逐步从实验室走向应用。作为环境感知的关键环节，交通标志检测（Traffic Sign Detection, TSD）负责为车辆提供限速、禁行、警告等关键道路信息，直接关系到车辆的决策逻辑与行驶安全。

然而，在实际的道路行车环境中，交通标志的实时检测面临着严峻挑战。首先，**多尺度问题显著**，摄像头拍摄到的交通标志在图像中的像素占比往往极低（小目标），导致特征信息模糊；其次，**环境干扰复杂**，光照变化（夜间、逆光）、恶劣天气（雨雾）以及树木车辆的遮挡，都会严重影响检测的鲁棒性；最后，**实时性要求高**，车载嵌入式设备的计算资源有限，算法必须在保证高精度的同时，具备低延迟的推理能力。

传统的检测算法难以兼顾精度与速度，而以 YOLO（You Only Look Once）为代表的单阶段深度学习算法虽然性能优异，但在上述极端场景下仍存在改进空间。因此，开展《基于 YOLO 模型的交通标志实时检测研究》，通过改进网络结构设计轻量化、高精度的检测算法，并结合软件工程方法开发实时检测系统，不仅具有重要的学术研究价值，更能为自动驾驶技术的工程化落地提供技术支撑，具有显著的社会效益和应用前景。

**(2) 国内外相关研究情况**
交通标志检测技术主要经历了传统图像处理与深度学习两个发展阶段。

**传统方法研究现状：**
早期的研究主要利用交通标志固有的颜色（如红、黄、蓝）和形状（如圆形、三角形）特征。例如，基于HSV或RGB色彩空间的阈值分割法，以及基于HOG（方向梯度直方图）特征结合SVM（支持向量机）的分类方法。此类方法计算简单，但泛化能力极差，难以适应光照变化和复杂背景干扰，已逐渐被淘汰。

**深度学习方法研究现状：**
近年来，卷积神经网络（CNN）成为主流。目标检测算法主要分为两类：
*   **双阶段算法（Two-stage）：** 如 R-CNN 系列（Faster R-CNN）。其精度较高，但检测速度通常低于 10 FPS，难以满足车载实时性需求。
*   **单阶段算法（One-stage）：** 如 SSD 和 YOLO 系列。YOLO 将检测视为回归问题，实现了端到端的快速检测。

**国内外研究动态：**
目前，YOLO 系列算法（v5/v7/v8）是该领域的首选基准。
*   **在模型轻量化方面：** 国外学者 Reis 等人（2023）提出了基于 YOLOv8 的无人机目标检测模型，验证了其在移动端的潜力；国内李志刚等人（2022）提出了 **GSConv（Ghost-Shuffle Convolution）**，通过轻量化卷积设计显著降低了计算量，非常适合自动驾驶边缘计算场景。
*   **在特征提取增强方面：** 为了解决背景干扰，注意力机制被广泛应用。**CBAM** 和 **SE** 模块虽然有效，但引入了额外参数。2019年 Yang 等人提出的 **SimAM (Simple Parameter-free Attention Module)** 是一种无参注意力机制，利用能量函数推导权重，在不增加模型负担的情况下提升了特征表达能力，成为近年来的研究热点。
*   **在损失函数优化方面：** 传统的 IoU 损失在低质量样本上收敛较慢。2023年 Tong 等人提出的 **WIoU (Wise-IoU)** 通过动态聚焦机制，有效解决了复杂场景下边界框回归不准的问题。

**存在的问题与切入点：**
尽管现有研究成果丰硕，但针对“资源受限下的高精度实时检测”仍有不足：原始 YOLOv8 模型在特征融合阶段计算冗余较大，且对远处微小标志的关注度不够。本课题拟结合 **GSConv 轻量化设计**与 **SimAM 无参注意力**，构建一种既快又准的 Slim-YOLO 检测模型，并基于 **ONNX Runtime** 实现工程化部署，以解决上述痛点。

---

**2. 本课题研究的主要内容和拟采用的研究方案、研究方法或措施**

**(1) 研究的主要内容**
本课题旨在设计并实现一个鲁棒性强、实时性好的交通标志检测系统，主要内容包括：
1.  **数据预处理与增强：** 基于 TT100K 或 CCTSDB 数据集，利用 Mosaic 和 Mixup 技术扩充训练样本，解决光照不均和遮挡问题。
2.  **Slim-YOLOv8 轻量化模型设计：** 改进 YOLOv8 网络结构，引入 GSConv 和 VoV-GSCSP 模块重构颈部网络（Neck），降低计算量（FLOPs）；引入 SimAM 无参注意力机制增强主干网络（Backbone）的特征提取能力。
3.  **训练策略优化：** 使用 WIoU (Wise-IoU) 替换原有的 CIoU 损失函数，提高模型在模糊、遮挡场景下的定位精度。
4.  **实时检测系统开发：** 基于 Python 和 PyQt5 开发图形用户界面（GUI），利用 ONNX Runtime 推理引擎对模型进行加速，实现对图片、视频及摄像头的实时检测功能。

**(2) 拟采用的研究方案（技术路线）**
本课题拟采用 **“轻量化网络结构 + 先进训练策略 + 工业级部署”** 的技术路线：

*   **基准模型选择：** 选用 **YOLOv8n (Nano)** 作为 Baseline，因其具备 Anchor-free 特性和极高的推理速度，适合作为实时检测的底座。
*   **网络结构改进（Model Optimization）：**
    1.  **特征融合轻量化（Slim-neck）：** 将 YOLOv8 Neck 部分的标准卷积（Conv）替换为 **GSConv**，将 C2f 模块替换为 **VoV-GSCSP**。GSConv 结合了标准卷积的精度与深度可分离卷积的速度，能有效保持多尺度特征（Multiscale Features）的传输，同时显著降低参数量和计算延迟。
    2.  **特征提取增强（Attention Mechanism）：** 在 Backbone 的 SPPF 模块前后嵌入 **SimAM (Simple Parameter-free Attention Module)**。不同于 CBAM，SimAM 不需要添加额外参数（MLP或卷积），而是基于神经科学理论推导三维注意力权重，在零参数增加的前提下，抑制复杂背景，聚焦交通标志特征。
*   **损失函数优化：**
    引入 **WIoU v3 (Wise-IoU)** 损失函数。利用其“动态非单调聚焦机制”，根据锚框的离群度（Outlier）动态分配梯度增益，重点优化普通质量的样本，减少低质量有害样本的干扰，提升模型收敛速度和最终 mAP。
*   **工程化实现：**
    模型训练完成后，使用 `torch.onnx.export` 将模型导出为工业通用的 **ONNX** 格式。系统开发阶段，使用 **PyQt5** 构建界面，底层调用 **ONNX Runtime** 进行推理加速，确保系统在普通 PC 或嵌入式设备上也能达到实时检测标准（FPS > 30）。

**(3) 研究方法或措施**
1.  **文献研究法：** 查阅 2023-2025 年间关于 YOLO 改进、GSConv、SimAM 的顶级会议论文，确立技术路线。
2.  **实验法（消融实验）：** 遵循控制变量原则，设计对比实验：
    *   Exp1: YOLOv8n (Baseline)
    *   Exp2: Baseline + SimAM
    *   Exp3: Baseline + GSConv (Slim-neck)
    *   Exp4: Baseline + SimAM + GSConv + WIoU (Ours)
    通过对比 Precision, Recall, mAP@0.5, FPS, GFLOPs 等指标，验证每个改进点的有效性。
3.  **软件工程方法：** 按照需求分析、概要设计（类图/流程图）、编码实现、测试验收的 SDLC 流程进行系统开发，注重代码规范和文档编写。

**3. 本课题研究的重点及难点，前期已开展工作**

**(1) 研究重点**
1.  **轻量化与精度的平衡：** 如何通过 GSConv 和 VoV-GSCSP 模块的设计，在大幅降低计算量的同时，确保对微小交通标志的特征融合能力不退化。
2.  **无参注意力的有效融合：** 确定 SimAM 模块在网络中的最佳插入位置（如 Backbone 末端或 Neck 连接处），以最大化特征增强效果。
3.  **工程化部署：** 实现从 PyTorch 到 ONNX 的无损转换，并基于 PyQt5 开发多线程的实时检测系统，解决界面卡顿问题。

**(2) 研究难点**
1.  **小目标漏检问题：** 交通标志在远距离下像素占比极小，经过多次下采样后特征易丢失。难点在于如何利用 Slim-neck 结构更好地保留浅层高分辨率特征。
2.  **复杂环境鲁棒性：** 模型易在特定数据集过拟合。难点在于如何结合 WIoU 损失函数和 Mosaic 数据增强，使模型在夜间或雨雾天也能准确识别。

**(3) 前期已开展工作**
1.  **资料收集：** 已阅读 YOLOv8 官方文档及《Slim-neck by GSConv》、《SimAM: A Simple, Parameter-Free Attention Module》等核心文献 20 余篇，完成了 3000 字的外文翻译。
2.  **环境搭建：** 已配置好 Python 3.8, PyTorch 2.1, CUDA 11.8 开发环境，并安装了 PyCharm 和 Anaconda。
3.  **数据准备：** 已下载 **TT100K (Tsinghua-Tencent 100K)** 数据集，编写 Python 脚本完成了数据清洗，将其转换为 YOLO 格式，并进行了 Mosaic 增强测试。
4.  **基准测试：** 已跑通 YOLOv8n 官方代码，能够进行训练和推理，初步记录了基准模型的 mAP 和 FPS 数据。
