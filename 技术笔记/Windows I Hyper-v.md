#### 一、前期准备与环境确认
1. **下载 Windows ISO 映像**  
   访问 [Microsoft 官网](https://www.microsoft.com/software-download) 下载所需版本的 Windows ISO 文件（如 Windows 10/11）。

2. **确认宿主机 Windows 版本**  
   - **要求**：Windows 10/11 **专业版**、**企业版** 或 **教育版**（家庭版不支持 Hyper‑V）。
   - **查看路径**：`设置` → `系统` → `关于` → 检查“Windows 规格”。

3. **启用 Hyper‑V 功能**  
   - 点击任务栏搜索图标，输入 `启用或关闭 Windows 功能` 并打开。
   - 勾选 **Hyper‑V**（确保子项全部勾选），点击“确定”，然后选择 **立即重新启动**。

#### 二、通过 Hyper‑V 管理器创建虚拟机
1. 在搜索栏输入 **Hyper‑V 管理器** 并打开。
2. 在右侧“操作”面板中点击 **新建** → **虚拟机**，启动新建向导。
3. **指定名称和位置**  
   - 输入虚拟机名称（如 `Win11-VM`）。  
   - 如需修改默认存储位置，勾选“将虚拟机存储在其他位置”并指定目标路径（建议非系统盘）。
4. **指定虚拟机代数**  
   - 选择 **第一代**（兼容传统 BIOS 引导，适合大多数 Windows ISO）。
5. **分配内存**  
   - 启动内存建议分配 **4096 MB（4 GB）以上**，并可根据需要勾选“为此虚拟机使用动态内存”。
6. **配置网络**  
   - 连接选择 **Default Switch**，使虚拟机可通过宿主机网络访问互联网。
7. **连接虚拟硬盘**  
   - 选择 **创建虚拟硬盘**，设置名称、存储位置（建议与虚拟机配置同一目录）及容量大小（通常 50 GB 起）。
8. **安装选项**  
   - 选择 **从可启动的 CD/DVD‑ROM 安装操作系统**。  
   - 点选 **映像文件（.iso）**，点击“浏览”选择已下载的 Windows ISO 映像文件。
9. **完成创建**  
   - 检查“摘要”页面的配置信息，确认无误后点击 **完成**。

#### 三、启动虚拟机并安装 Windows 系统
1. 在 Hyper‑V 管理器主界面，右键单击新建的虚拟机，选择 **连接…**。
2. 在弹出的控制台窗口中点击 **启动** 按钮。
3. 虚拟机将引导至 Windows 安装程序，按照屏幕提示完成语言选择、许可条款确认、分区设置及用户账户配置等常规安装流程。
4. 安装过程中虚拟机可能会自动重启，无需干预，直至进入 Windows 桌面。
