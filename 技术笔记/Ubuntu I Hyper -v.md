#### 一、确认 Windows 版本

- **要求**：Windows 10/11 **专业版**、**企业版** 或 **教育版**（家庭版默认不支持 Hyper‑V）。
    
- **检查路径**：`设置` → `系统` → `关于` → 查看“Windows 规格”中的版本信息。
    
#### 二、启用 Hyper‑V 功能

1. 点击任务栏 **搜索图标**，输入 `启用或关闭 Windows 功能` 并打开。
    
2. 在列表中勾选 **Hyper‑V**（确保其子项全部自动勾选）。
    
3. 点击 **确定**，等待配置完成后选择 **立即重新启动**。
    
#### 三、修改 Hyper‑V 默认存储路径（可选但推荐）

> 目的：避免虚拟机文件和虚拟硬盘占用 C 盘空间。

1. 在搜索栏输入 **Hyper‑V 管理器** 并打开。
    
2. 在右侧 **操作** 面板中点击 **Hyper‑V 设置…**。
    
3. 分别修改以下两项的路径至其他盘符（如 `D:\Hyper‑V\`）：
    
    - **虚拟硬盘**（默认存放 `.vhdx` 文件）
        
    - **虚拟机**（默认存放虚拟机配置文件）
        
4. 点击 **确定** 保存设置。
    
#### 四、快速创建 Ubuntu 22.04 LTS 虚拟机

1. 在 Hyper‑V 管理器右侧点击 **快速创建…**。
    
2. 在左侧操作系统列表中选择 **Ubuntu 22.04 LTS**（若未列出，可手动下载镜像后选择“本地安装源”）。
    
3. 点击右下角 **创建虚拟机**，系统将自动下载镜像并完成基础配置。
    
4. 等待创建进度条结束，点击 **连接** 进入虚拟机控制台窗口。
    
5. 点击控制台工具栏中的 **启动** 按钮，虚拟机开始引导。
    
#### 五、正常安装 Ubuntu 系统

- 进入 Ubuntu 安装界面后，按常规流程选择语言、键盘布局、安装类型（推荐“正常安装”）等。
    
- 设置用户名、密码及计算机名称，等待安装完成。
    
- 安装结束后根据提示 **重启虚拟机**，即可进入 Ubuntu 22.04 LTS 桌面环境。


#### 六、常见问题处理：启动后蓝屏提示 `login to xxx-Virtual-Machine`

如果在首次启动时出现蓝屏登录界面（非图形化桌面），可尝试切换会话模式解决：

1. 在虚拟机连接窗口左上角菜单栏中，点击 **查看** → **切换到基本会话**。
    
2. 在弹出的登录界面中输入安装时设置的用户名和密码。
    
3. 成功登录后，系统通常会自动加载完整桌面环境。
    

若问题依旧存在，建议检查虚拟机集成服务是否已安装，或尝试在虚拟机设置中调整显示适配器的显存大小。
